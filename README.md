# Orbenyx-Portfolio

> Dual-sequence cinematic portfolio website for Orbenyx Digital Studio, engineered with GSAP ScrollTrigger, Lenis smooth scrolling, canvas video orchestration, and interactive particle dynamics.

## Features
- **Dual Canvas 2D Video Orchestration**: Frame-by-frame scroll scrubbing for high-resolution WebP sequences (Logo Explode & Rock Reveal).
- **Smooth Inertia Scrolling**: Powered by Lenis with dynamic ScrollTrigger synchronisation.
- **Vertical Strips Transition**: Choreographed multi-panel curtain wipes between cinematic sections.
- **Interactive Particle Dynamics**: Cyber dust, constellation nodes, and spark burst simulations.
- **Responsive Architecture**: Fully responsive layouts tailored for ultra-wide desktop to small mobile viewports.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- GSAP 3 & ScrollTrigger
- Lenis Smooth Scroll
- Vite Dev & Build Tooling

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
